# recettes
Stage - 1ére année

Un site web de recettes moderne et attrayant, développé avec Django.  
Il offre une expérience utilisateur complète : création de compte, découverte de recettes, publication des vôtres, et interactions avec la communauté.

Fonctionnalités principales :
- Création de compte et authentification
- Publication et consultation de recettes
- Commentaires et système de notation
- Moyenne des notes affichée pour chaque recette
